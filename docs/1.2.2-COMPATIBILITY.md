# 1.2.2: coin price context and CustomScoreboard

`Mana Cost`, `Soulflow Cost`, health/energy costs and other compound resource labels are
not coin prices. Bare `Cost:`/`Price:` fields must be complete price labels with no foreign
unit, percentage or stat glyph. Explicit `N coins` amounts still work anywhere, including
purchases combining coins with another resource; only the coin portion is converted.

Optional compatibility targets **meowdding/CustomScoreboard**, specifically the published
**1.12.11 build for Minecraft 26.1.x** (Modrinth version `9ZQ8S1sQ`):

- Standard Purse/Piggy elements, all four label/number placements.
- Label-free PURSE values in Chunked Stats (other chunked currencies stay unchanged).
- Uncustomized Hypixel Lines, including the section-p purse-formatting fix.

Conversion runs before widget sizing and alignment. CustomScoreboard retains its layout,
background, actions and visibility controls. Coins to Money's sidebar toggle controls
these adapters too; money/cookies remain green and original/gain styles are retained.
No CurrencyAPI balance or server scoreboard is modified. Rounded/compact purse displays
are converted at their displayed precision. No standalone HUD is added.

CustomScoreboard and Kotlin are **not required** by Coins to Money and are not bundled.
Install CustomScoreboard's own dependencies normally when using it. Optional hooks are
scoped to that mod's display methods, not a global font hook. This is not a promise of
compatibility with future versions that replace those methods or unrelated scoreboard mods.

CI boots both without the optional mods and with the unmodified 1.12.11 binary and its
libraries, exercising real formatter/widget hooks, widths, green colours, chunked values,
unchanged non-coin resources and settings rendering. Inputs are synthetic, not a logged-in
Hypixel session. The compatibility log is included with the test artifact.
