# 1.2.3 integration scope and verification

## CustomScoreboard

Test target: meowdding/CustomScoreboard 1.12.14-2 for Minecraft 26.1, Modrinth `5VSiG5l7`.
The 1.2.2 adapter inferred money from a US-formatted visible number. That fails on localized
forms such as `7.416.701` and can use rounded values for compact forms such as `7.42M`.
1.2.3 reads `CurrencyAPI.getPurse()` without changing it. The typed adapter finds the visible
number span but uses the unrounded coin amount for money/cookies. Original coin text and gain
text keep their styles. Unknown/unavailable APIs fall back only when the displayed amount can
be parsed safely; they never invent a balance.

Hooks cover Component and string `formatNumberDisplayDisplay`, PURSE-only chunk suppliers,
and `ScoreboardLineKt.asTextWidget` for Hypixel Lines. Adapters run before the native builder
measures and arranges widgets. Native `LocationAPI.isOnSkyBlock` also keeps quote refresh active
when the vanilla objective is not the source of the visible sidebar.

CI builds the actual native scoreboard using PurseElement, under US/German/French locales,
LONG/SHORT number formats and all four native label placements. It checks precise money from
7,416,701 coins, preserved (+5), green equivalents, widths, disabling, absent quote handling,
chunk suppliers, the string overload and unchanged native balance. Real native widgets render
alongside the settings fixture. Non-coin labels and chunks are checked unchanged.

## SkyHanni

Test target: hannibal002/SkyHanni 7.56.0 for Minecraft 26.1, Modrinth `MnRBvQlm`.
`ItemPriceUtils.formatCoin(Number, boolean)` is a semantic price formatter. Its raw Number is
used for conversion; the generic `NumberUtil` is never intercepted. This covers price breakdowns
used by chest-profit overlays and shared item trackers, without changing revenue, cost, sorting
or net-profit arithmetic. Negative amounts retain their minus sign.

The crop-money price-cell lambda is separately adapted, including its raw extra-per-hour input.
It does not change crop counts, XP, fortune or efficiency. String/Component Renderable display
adapters additionally recognize explicit coins and narrowly defined profit/money-per-hour labels.
They keep immutable original text and use the same projection for getText, getWidth and rendering.
No global Font or generic-number hooks are installed. Mana/Soulflow/resource cost safeguards
remain independent and are not broadened for SkyHanni.

Display changes request TrackerManager's native self-clearing update flag, not a permanently
true dirty flag. Native overlays with their own cached strings refresh on their usual event;
a chest overlay may need reopening after settings changes. Conversion cannot be shown before
a usable Bazaar quote exists. Already rounded labelled values are converted at their available
precision; semantic scalar and crop cells use the actual Number provided by SkyHanni.

CI invokes actual ItemPriceUtils formatting, InstanceChestProfit.buildDisplay with a signed
price map, FishingProfitTracker's shared addTotalProfit implementation, the crop-price lambda,
and StringRenderable/TextRenderable widths and rendering. It checks negative profits, the
selected currency, toggling on an existing renderable, non-coin fields, typed coin units and
native tracker invalidation, with all calculations/input maps left numeric and unchanged.

## Test configurations and limits

Four isolated clients run: neither optional mod, CustomScoreboard, SkyHanni, both. Published
binaries and required primary dependencies are pinned by URL and SHA-512. Test classes are in
a separate Fabric source set and never included in the release. Each configuration renders
120 settings/currency frames. Do not install the smoke-test mod or source JAR.

No authenticated Hypixel account is used. These tests verify the named binary versions and
actual method/widget paths with synthetic fixtures; unknown versions, third-party replacement
renderers and every possible server UI variant are not claimed. Clipboard diagnostics include
mod versions, context/quote state and adapter activity, but no automatic telemetry is sent.
